md，全称markdown，一种标记语言，语法简单明了，编辑的文本工整好康

不管是转换成网页语言（html），还是转换成pdf，都极为方便

我觉得这是ai时代下不得不学的一个内容，或者说是个比较实用的工具：现在所有ai软件、网站等，向用户反馈的文本都是md格式的；

那么，下面是一些最基础的也是最常用的语法：

## 1.

```
#（空格）     一级标题

##（空格）    二级标题

...

以此类推，一般最多到六级标题
想要更换具体某一行的标题层级，除了原生语法井号，本软件（即typora），还可以通过快捷键 ctrl+1/2/3/4/5/6
```

## 2.

``` 
*内容*       斜体字
**内容**     加粗字体
```

## 3.

```
​```（找不到这个符号？这不是单引号，这是键盘最左上角，数字1左边，esc下方，和波浪线~在一块儿的一个符号，英文输入法）
代码           代码块（说是代码块，我一般也把它当作一个带深色背景的文本框来用）
​```

想要召唤代码块，除了原生语法```，本软件（即typora），还可以通过快捷键ctrl+shift+k来召唤
```

## 4.

```
==内容==     高光
~~内容~~     划线
```

## 5.

```
-（空格）    无序枚举
数字（空格）  有序枚举
```

## 6.

```
$内容$      

行间插入公式，说到这里，又推荐大家简单了解以下latex了，如果有兴趣的话（数学公式，化学方程式等等有妙用，虽然语法真的很繁琐）
```

## 7.

```
---（回车）     分割线
```

## 8.

```
![]()     从本地选择图片

[这里写链接的名称](这里写链接或者本地某个图片的路径)

注意：！！！请确保你写入md文本的图片存放位置不变或不丢失！！！否则至少要写一个长期有效的链接例如：https://images.unsplash.com/photo-1500937386664-56d1dfef3854?auto=format&fit=crop&w=400&q=80

亦或者！！！进入左上角偏好设置（ctrl+逗号），选择  复制图片到./${filename.assets 文件夹  ！！！


存放到你电脑上的图片路径相当于小区单元楼，世界上可以有无数个一号楼二号楼，因此，你本地有的图片发给别人是不会一并发过去的；
而链接则相当于完整的地图引导，哪个国家，哪个省，哪个市区，哪个城镇的几号街哪个小区几号楼几单元几层楼，将链接写入md，发给别人，别人可以看到


亦或者，如果你只是希望自己写入md中的图片被别人看到，那么，请看本文9.吧
```

## 9.

```
关于导出，本软件（typora）左上角，导出功能是个很好用的功能

延续8.，如果你希望自己撰写的配图被其他人看到，那么就：
文件-导出-PDF
把这个PDF发给别人吧，这是直接把你的配图嵌入进去了（html中的逻辑和md的逻辑相同，因此，不要导出html发给别人，纯文本除外）
```

## 10.

### 可能遇到的问题：

也许有时候你会遇到本软件导出功能失效，pdf无法导出了，只能导出其他格式了，不用慌，大概率是windows系统底层的一个什么print程序挂掉了，问问豆包或什么其他ai，一步一步指引下去，你会找到它并重启它然后重新成功导出的
