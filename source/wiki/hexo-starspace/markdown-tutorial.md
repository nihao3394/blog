# Markdown 简明教程

本人在此简单讲解 Markdown（后面简称md）的相关内容。

如果你曾经被 Word 繁琐的排版字体大小调整折磨得抓狂，或者在 AI 交互时被一堆带星号 `**` 和井号 `#` 的奇奇怪怪符号搞得一脸懵逼，恭喜你，你已经站在了 Markdown 的大门前。

> 简单来说：Markdown 就是用不同的、简单易记的符号，丰富纯文字表现的一套语言规范。它能变成网页、PDF、笔记、文档，还能被 AI 快速识别出来。

------

## 0. md 是个啥？

**md**，全称 **Markdown**，是一种**标记语言**。

“标记”这个词听起来有些学术，实际意义很朴素：在文字旁边再加上几个约定好的符号，告诉软件“这行是标题”、“这个词需要强调”，软件读懂之后，负责把文字渲染成对应的样式。

你可能会问：Word 里点一下"加粗"按钮不就行了吗，为什么要多学一套符号？和Word一类的排版软件相比，它的取舍很明显：**放弃了花哨的界面，换来了极低的学习成本和极强的通用性**，因为 Markdown 有几个 Word 比不了的优点：

- 语法极简：常用符号不超过十个，几乎无任何记忆负担；
- 双手无需离开键盘：感觉word调整每一部分的字体效果点来点去很麻烦、效率太低？md可以让你写字、排版全程键盘操作，不需要在输入和鼠标菜单之间来回切换，思路更不容易被打断；
- 转换方便：相同的文本，可以快速转为网页（HTML）、PDF等格式；
- 纯文本存储：word不同版本造成的格式显示千差万别的问题相信是一个为祸久矣的问题，由于md使用纯文本字符编写而成，任何设备均可打开，不依赖特定软件版本，且显示效果一致；又因为式纯文本字符编写而成，因此文件体积很小；

------

## 1. 为什么说它是 AI 时代"不得不学"的东西？

回忆一下：无论是ChatGPT、豆包、Kimi还是Claude，AI的回复里是否时常夹杂着`#`、`-`、`**`此类的符号？

这不是 AI 在输出乱码，这就是 **Markdown**。

现在几乎所有 AI 软件和网站，给用户的反馈**默认都是 md 格式**。你要是看不懂它，就好比去了国外却不认识路牌：虽然也能活，但总觉得哪里别扭。

具体来说，掌握它至少有三点实际好处：

1. **读得懂AI的输出**：明确哪里是标题、哪里是代码、哪里是重点。
2. **指令更准确**：让AI“用Markdown表格整理”，得到的结果通常比一句“整理一下”规范。
3. **笔记内容更通用**：Typora、Obsidian、Notion等高效主流笔记与文档工具，都原生支持系统语法；不仅如此，就我本人的使用体验而言，现在的安卓系统自带的文本编辑器也都开始普及md语法了；很多开源软件也会支持md格式；全球最大的开源社区之一github每个仓库都会有一份README文件，也是由md格式写成的。

------

## 2. 工欲善其事：用什么软件写 md？

md 本质上是**纯文本**，用系统自带的记事本都能写。但那样你看到的永远是一堆符号，看不到排版后的效果，有点像做菜只看菜谱、不上桌（截至写作本文时候的2026.10.10，windows自带的“记事本”功能依然没有支持md渲染功能，虽然它自带的字效已经很好用）。

所以我们需要一个"能实时预览"的编辑器。本文推荐：

- **Typora**：本文使用的软件。所见即所得，敲完符号，它立刻会渲染成好康的格式，非常适合新手。
- **VS Code**：程序员常用，装个预览插件也能写。
- **Obsidian**：同样“所见即所得”，做笔记、搭知识库很强，互联网上的教程资源也属它最多，喜欢折腾的不妨试试。

> 本文后面提到的快捷键、设置路径，默认都以 **Typora** 为例。用别的软件的同学，语法是通用的，快捷键可能略有不同。

------

## 3. 基础语法

以下是最基础、最常用的语法。

### 3.1 标题

```
# 一级标题
## 二级标题
### 三级标题
...（以此类推，一般最多支持到 ###### 六级标题）

Typora:快速切换某一行的标题级别，无需手动敲 #，直接按快捷键 Ctrl + 1/2/3/4/5/6 即可。Ctrl + 0 则是把它变回普通段落。
```

效果：

# 这是一级标题

## 这是二级标题

### 这是三级标题

...

规则很简单：**几个 `#` 就是几级标题，`#` 后面一定要跟一个空格**。

这个空格是新手最容易漏掉的细节。没有空格，电脑会认为你只是在打一个普通的井号，不会帮你变成标题。

标题一般最多到**六级**，再往下就太细了，写文章的人自己都会绕晕。

### 3.2 斜体和加粗

```
*内容*        → 斜体
**内容**      → 加粗
***内容***    → 又粗又斜
```

效果：*这是斜体*，**这是加粗**，***这是又粗又斜***。

符号和文字之间**不要加空格**，写成 `** 内容 **` 通常会失效。

### 3.3 代码块

代码块用**三个反引号**（注意：反引号是键盘上方数字1左边紧邻的那个按键下输出的引号，不同于键盘中右侧的”单引号“）包起来：

```
​```
这里放代码，或者任何你想原样展示的文字
​```

Typora：快捷键 `Ctrl + Shift + K` 可以直接召唤代码块，不用去找那个难按的符号。
```

效果：

```c++
# include<iostream>

int main() {
    std::cout << "hello world" << endl;
}
```

**它能用来做什么？**

- 本职用途：展示代码。空格与缩进都会被原样保留。
- 更广泛的用途：我个人习惯把它当作一个**带测量背景的文本框**，需要让某段内容自成一体、快速可辨认时，就丢掉。
- 想复制一大段文字给别人，放在代码块里最方便，右上角往往还自带一键复制（比较尴尬的是Typora不支持这个功能）。

**行内代码**：如果只是想把某几个词单独标出来（比如 `这样`），只需要用**一对反引号**包住它们，不用整块。

### 3.4 高光和划线

```
==内容==      → 高光
~~内容~~      → 划线（删除线）
```

效果：==这是高光==，~~这是被划掉的内容~~。

- **高光**适合标记重点，像拿荧光笔涂过一样。
- **划线**适合表示"这个不要了"，比如待办清单里完成的事项，或者写出"我才不吃夜宵~~（真香）~~"这种自我打脸的效果。

> 注意：划线几乎所有软件都支持，但高光属于**扩展语法**。在 Typora 里如果 `==内容==` 没有变成高光，可以到**偏好设置 → Markdown** 里，勾选"高亮"（Highlight）选项。换成别的软件，也可能不支持这个语法。

### 3.5 列表

1. **无序列表**，用 `-` 加空格：

```
- 苹果
- 香蕉
- 橘子
```

效果：

- 苹果
- 香蕉
- 橘子

2. **有序列表**，用数字加点再加空格：

```
1. 打开软件
2. 新建文件
3. 开始写作
```

效果：

1. 打开软件
2. 新建文件
3. 开始写作

**想要"列表里面套列表"？** 在下一行按 `Tab` 键缩进一下就行：

- 水果
  - 苹果
  - 香蕉
- 蔬菜
  - 白菜

**待办清单**也很好用，写法是 `- [ ]` 和 `- [x]`：

```
- [x] 学会标题
- [ ] 学会公式
- [ ] 吃夜宵

这个在typora中敲可能会遭遇无序列表的强人所难，你可以试着按照这个顺序稳定地敲出选择框：
1. -
2. -[空格]空格
3. -空格[空格]空格
```

效果：

- [ ]  学会标题
- [ ]  学会公式
- [ ]  吃夜宵

### 3.6 公式

用一对 `$` 把内容包起来，就能在行内插入公式。比如：

```
$E=mc^2$
```

效果：$E=mc^2$

这背后用到的是一门叫 **LaTeX** 的语言。如果你的专业涉及数学、物理、化学，经常要写公式或方程式，那么非常建议你有空**简单了解一下** LaTeX。本资料同样附带了一份我自己编写的LaTeX语法教程，专用于适配md文档，感兴趣的可以移步“LaTex语法基础.md”。

坦白讲，它的语法确实繁琐，初学时会有"这是什么外星文字"的感觉。但一旦掌握，写出来的公式又整齐又专业，投入绝对值得。如果你暂时用不到，可以先跳过，以后再回来。

> 如果想写独占一行的大公式，可以用两对美元符号：`$$公式$$`。例如：

```latex
$$
\int^{a}_{b}f(x)\,dx
$$
```

效果：
$$
\int^{a}_{b}f(x)\,dx
$$


### 3.7 分割线

```
---
```

输入三个短横线，然后按回车，页面上就会出现一条横线。

它适合用在话题转换的地方，起到"换个场景"的作用，就像电影里的转场。

### 3.8 引用

在句子前面加 `>` 和一个空格：

```
> 这是一段引用。
```

效果：

> 这是一段引用。

适合引用名言、强调提示，或者像本文这样，放一些"划重点"的小注解。

### 3.9 表格

```
| 水果 | 价格 | 好吃程度 |
| --- | --- | --- |
| 苹果 | 5 元 | 还行 |
| 榴莲 | 30 元 | 爱的人爱死 |

typora：可以用快捷键 `Ctrl + T` 直接插入表格，再往格子里填内容就行。
```

效果：

| 水果 | 价格  | 好吃程度           |
| ---- | ----- | ------------------ |
| 苹果 | 5 元  | 还行               |
| 榴莲 | 30 元 | 萝卜青菜，各有所爱 |

用 `|` 分隔每一列，第二行的 `---` 表示表头和内容的分界。

### 3.10 图片和链接

基本写法：

```
[这里写链接的名称](这里写链接地址)
![图片的说明文字](图片的地址或路径)

Typora：你也可以直接把图片拖进去，或者复制后粘贴，它会自动帮你生成这行代码。亦或者，输入![]()唤起windows文件选择页手选。
```

**图片比链接多一个感叹号 `!`**，其余几乎一模一样。

==以下内容请格外注意！！！==

#### 本地图片和网络图片

**本地图片：写进去的只是“地址”，而不是“图片”**

你插入图片时，md文件里记录的只是一个**路径**，比如`E:\桌面\图片.png`，图片本身并没有被存进文本里。

可以这样理解：

> 本地路径，相当于“3号楼2单元”这种**楼内编号**。全世界有无数个小区都有3号楼，你电脑里有，别人电脑里也有，但不是同一栋。
>
> 因此，当你把 md文本 发给别人，对方的软件按照这个索引查找，找到的可能是其他图，可能什么也没有。

而**网络链接**则相当于一个**完整的地址**：国家、省、市、区、街道、小区、几号楼、几单元、几层。 无论谁拿到手，都能定位到同一个地方。

#### 如何避免？

方法一：使用网络链接

链接就像一张**完整的地图导航**：哪个国家、哪个省、哪个市、哪条街、几号楼、几单元、几层。不管谁拿到它，都能准确找到地方。

所以，只要图片有一个**长期有效的网络链接**，写进 md 里，别人也能看到。例如：

```
![风景](https://images.unsplash.com/photo-1500937386664-56d1dfef3854?auto=format&fit=crop&w=400&q=80)
```

方法二：让软件替你保管图片

打开 Typora 左上角的**偏好设置**（快捷键 `Ctrl + 逗号`），找到图像相关的设置，选择：

```
复制图片到 ./${filename}.assets 文件夹
```

这样，你每次插入图片，软件都会自动把图片**复制一份**，放进和 md 文件同名的 `.assets` 文件夹里。以后你要搬家，把 md 文件和这个文件夹**一起**打包带走，图片就不会丢。

> 记住是**一起带走**。只带 md 文件不带文件夹，那就等于白设置。

方法三：直接导出为 PDF

如果你只是想让别人看到你写好的内容，那就看下一节。

## 4. 导出：把成果发给别人

Typora 左上角有一个很好用的功能：**导出**。

如果你希望自己写的图文被别人看到，最稳的做法是：

```
文件 → 导出 → PDF
```

然后把这个 PDF 发给对方。PDF 会把你的配图**直接嵌进文件里**，对方打开就能看，不会出现"图片丢失"的尴尬。

#### 为什么不建议导出 HTML 发给别人？

因为 HTML 和 md 的"找图逻辑"是一样的：它记录的也是图片的**路径**，而不是图片本身。你把 HTML 发给别人，同样会遇到"一号楼"问题。

**例外**：如果你的内容是**纯文本**，没有图片，那么导出 HTML 发过去是完全没问题的。

上面的内容总结如下：

| 导出格式      | 内容含本地图片               | 内容是纯文本 |
| ------------- | ---------------------------- | ------------ |
| **PDF**       | ✅ 图片已嵌入，放心发送       | ✅ 没问题     |
| **HTML**      | ❌ 图片可能丢失               | ✅ 没问题     |
| **md 原文件** | ❌ 需连同 assets 文件夹一起发 | ✅ 没问题     |

## 5. 可能遇到的问题

### 问题：导出功能失效，PDF无法生成

这个问题并不罕见，**大概率的原因**是：Typora依赖的某个Windows系统底层打印程序（打印服务）停止运行了。底层依赖打印功能产生了问题，导出自然会失败。

**如何解决**：

1. 先临时改用其他格式导出，别耽误正事。
2. 然后问问**豆包**或者其他 AI，把你的情况描述清楚，比如"Typora 导出 PDF 失败，怎么重启 Windows 的打印服务"。
3. 跟着它**一步一步**往下做，你会找到那个"挂掉的程序"，把它重启，之后就能重新成功导出了。

### 其他常见问题

- **符号没生效？** 先检查是不是漏了空格（比如 `#` 后面），或者多了空格（比如 `**` 和文字之间）。
- **想打出符号本身，不想让它变格式？** 在前面加一个反斜杠 `\`。比如 `\*不是斜体\*` 会原样显示 *不是斜体*。
- **想换段落？** 中间空一行。只按一次回车，有些软件会把它们当成同一段。
